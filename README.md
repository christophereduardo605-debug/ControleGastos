# Controle de Gastos Pessoais

Projeto desenvolvido para uma atividade da faculdade, utilizando React Native com Expo.

## Sobre o projeto

O aplicativo foi criado para ajudar no controle de gastos pessoais. Nele é possível cadastrar um gasto informando a descrição e o valor, visualizar os gastos cadastrados e acompanhar o total gasto.

Também é possível excluir gastos e os dados ficam salvos no celular, mesmo depois de fechar o aplicativo.

## Funcionalidades

- Cadastrar gastos com descrição e valor
- Validar os campos antes de salvar
- Listar os gastos cadastrados
- Calcular o total automaticamente
- Excluir gastos
- Salvar os dados usando AsyncStorage
- Navegar entre as telas

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage

## Como executar

1. Instalar as dependências com `npm install`
2. Iniciar o projeto com `npx expo start`
3. Abrir o aplicativo no Expo Go
